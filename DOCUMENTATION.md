# Документация приложения: Logistics Route Optimizer

## 1. Назначение
Приложение предназначено для автоматизации и оптимизации процессов транспортной логистики. Оно решает задачи распределения заказов по транспортным средствам (VRP) и нахождения кратчайших путей объезда точек (TSP).

## 2. Основные компоненты

### 2.1. Карта (Map Module)
Центральный элемент интерфейса.
- **Технология:** Leaflet.
- **Функции:** 
  - Отображение склада (Warehouse) и заказов (Orders).
  - Визуализация маршрутов с учетом реальной дорожной сети (OSRM).
  - Инструмент "Lasso" для группового выделения точек.
  - Интерактивные попапы с информацией о заказах.

### 2.2. Управление заказами (Order Management)
Левая боковая панель.
- **Импорт:** Поддержка загрузки файлов Excel (.xlsx).
- **Фильтрация:** Поиск по названию клиента, коду или региону.
- **Статусы:** Разделение заказов на "В маршруте" и "Свободные".

### 2.3. Планирование и Оптимизация (Routing & Optimization)
Правая боковая панель.
- **Авто-планирование:** Запуск комплексных алгоритмов распределения.
- **Оптимизация маршрута:** Кнопка "Волшебная палочка" на каждом маршруте открывает сравнение алгоритмов (NN, 2-Opt, Greedy).
- **Оптимизировать все:** Глобальная функция пересчета всех маршрутов по реальным дорожным путям.

## 3. Алгоритмическая база

### 3.1. Геометрия и Дистанции
- **Haversine Formula:** Используется для быстрых предварительных расчетов (расстояние по прямой).
- **OSRM API:** Используется для получения реальных дорожных путей и матриц расстояний (Table Service).

### 3.2. Методы оптимизации
1. **Nearest Neighbor:** Поиск ближайшей точки.
2. **2-Opt:** Локальная оптимизация путем перестановки ребер.
3. **Greedy Selection:** Жадное построение графа пути.
4. **Clarke-Wright Savings:** Классический алгоритм для формирования маршрутов из депо.
5. **Метаэвристики:** В приложении реализованы заглушки/базовые версии алгоритмов имитации отжига (Simulated Annealing), генетического алгоритма и поиска с запретами (Tabu Search).

## 4. Технические детали
- **Язык:** TypeScript.
- **UI:** React + Tailwind CSS.
- **Анимации:** Framer Motion.
- **Иконки:** Lucide React.
- **Графики:** Recharts.

## 5. Инструкция пользователя
1. **Загрузите данные:** Используйте кнопку "Импорт Excel" или работайте с демо-данными.
2. **Выберите заказы:** Используйте список слева или инструмент "Лассо" на карте.
3. **Создайте маршрут:** Нажмите "Создать" в панели маршрутов.
4. **Оптимизируйте:** Нажмите "Оптимизировать все" для пересчета путей по реальным дорогам.
5. **Сохраните:** Используйте вкладку "Сценарии" для сохранения текущей версии планирования.
