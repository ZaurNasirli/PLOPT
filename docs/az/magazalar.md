# Mağazalar — sorğu kitabçası

Mağazalar sorğu kitabçası bütün modulların ortaq mağaza bazasıdır: kod, ad, koordinatlar, region, format və əlaqə məlumatları. Yol, Ritm və Proqnoz koordinatları və adları buradan götürür.

## 1. Mağazalar necə əlavə olunur

- **Avtomatik:** Yol, Ritm və ya Proqnoz-da fayl idxal edəndə yeni mağazalar sorğu kitabçasına özü düşür.
- **Əllə:** **Mağaza əlavə et** düyməsini basın, kodu və ya adı yazın (biri mütləqdir), qalan sahələri doldurun və **Yadda saxla** basın.
- **Excel ilə:** **Excel-dən idxal** düyməsi. Faylda ən azı mağaza kodu və ya adı sütunu olmalıdır.

## 2. Mağaza kartı

Mağazaya basın, kart açılır. Sahələr:

- **Kod**, **Ad**, **Region**, **Format**;
- **Ünvan**, **Enlik**, **Uzunluq** (və ya bir sütunda **Koordinatlar**);
- **Əlaqə şəxsi**, **Telefon**;
- **Qəbul vaxtı** (məsələn, «07:00 - 23:00» və ya «7/24»);
- **Giriş və boşaltma** — maşın necə girir, harada boşaldır;
- **Maşın məhdudiyyətləri** — ölçü, çəki, qoşqu qadağası;
- **Qeydlər**.

Koordinatı olmayan mağazalar siyahıda «koordinatsız» kimi qeyd olunur. Belə mağaza Yol-da xəritədə anbarın yerində görünür, ona görə koordinatı doldurmaq vacibdir.

## 3. Axtarış və filtr

Yuxarıdakı axtarış sahəsinə kod, ad və ya ünvan yazın. Region və format üzrə filtr seçin.

## 4. Fayl və sorğu kitabçası fərqlənəndə

İdxal zamanı fayldakı ad, region və ya koordinatlar sorğu kitabçasından fərqlənərsə, proqram pəncərə açır: hər mağaza üçün **Sorğu kitabçası** və ya **Fayl** seçin, ya da hamısı üçün birdən (**Hər yerdə sorğu kitabçası** / **Hər yerdə fayl**). Sorğu kitabçasındakı boş sahələr fayldan sualsız doldurulur.

## 5. İxrac və silmə

- **Excel-ə ixrac** — bütün sorğu kitabçasını faylda saxlayır.
- **Sil** — mağazanı sorğu kitabçasından silir (təsdiq soruşulur). Bu, Yol, Ritm və Proqnoz-dakı sifarişlərə təsir etmir.

## 6. Mağazalar arası daşıma

Yol-da daşıma əlavə edəndə göndərən və alan mağazalar bu sorğu kitabçasından və cari sifarişlərdən seçilir. Mağazanın koordinatları düzgün olmalıdır, əks halda reysin kilometri səhv hesablanar.
